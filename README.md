# HyBroadcaster

HyBroadcaster is a simple announcement mod for Hytale servers. It allows administrators to send global messages to all players using two different display modes: center screen titles and toast notifications.

## Features

- Center screen announcements with custom title and subtitle.
- Announcements are broadcasted to everyone in the chat (using the toast option).
- Manual permission check (requires operator or hybroadcaster.admin).

## Commands

- /announce <message>: Displays a large title in the center of the screen for everyone.

## Installation

Place the HyBroadcaster.jar into your server's Mods folder and restart the server.
